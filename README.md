# Florida Citizens for Science GitHub Pages

Static organization site for [Florida Citizens for Science](https://www.flascience.org/).

- `index.html` is the organization landing page.
- `research/index.html` is the Research landing page.
- `research/florida-science-standards-review/` contains the standards-review pages and public analysis data.
- `research/timeline.html` and `research/timeline.json` record dated review milestones.
- `assets/site.css` contains the shared organization-site styling.

The site is designed for GitHub Pages from the `main` branch, repository root. The standards-review report retains its own corpus notes, source links, methods, and limitations.

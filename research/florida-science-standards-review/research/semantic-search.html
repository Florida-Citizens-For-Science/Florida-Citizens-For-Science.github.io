Local semantic search

The corpus now has a reproducible, offline semantic retrieval workflow. It is separate from the knowledge graph: search similarity is a discovery aid, not evidence of authorship, transmission, or copying. Confirm every candidate in the cited source passage and its version before making a provenance claim.

Build and query

Prepare a query from the graph

When you arrive from a graph item, its wording is prefilled here. This prepares a command for the local corpus index; it does not run a search on this public page.

python3 tools/semantic_search.py query … -k 10

Requirements in the current environment: Python 3, NumPy, SciPy, scikit-learn, PyMuPDF (fitz), and catppt for legacy .ppt files. Build the full-corpus index and then query it:

python3 tools/semantic_search.py build
python3 tools/semantic_search.py query "expect contrary opinions because interpretations of the same climatic data can vary widely" -k 10
python3 tools/semantic_search.py query "greenhouse model climatic data contrary opinions" --source sources/2026 -k 10
python3 tools/semantic_search.py inventory

The default lsi backend combines normalized word and two-word TF-IDF cosine similarity (55%) with cosine similarity in a deterministic 128-dimensional TruncatedSVD latent-semantic space (45%). It is a lightweight, corpus-trained semantic retrieval method, not a pretrained neural embedding. --backend lsi can be supplied explicitly. Artifacts are written under .semantic-search/lsi/; source chunks and the inventory are in .semantic-search/chunks.jsonl and .semantic-search/inventory.json.

An optional --backend jina path is implemented for the cached jinaai/jina-embeddings-v4 snapshot. It runs with HF_HUB_OFFLINE=1, uses the retrieval task, passage/query prompts, 256 dimensions, and 512-token truncation; it does not download weights. A direct CPU smoke check loaded the cached model and embedded a short input successfully, but one short query took about 18.6 seconds after load, and a batch of eight had not completed after more than 40 seconds. The refreshed corpus produces 36,568 chunks, so full-corpus CPU inference is not practical. The complete corpus index is therefore the LSI backend. Jina indexing is resumable by chunk if explicitly invoked, and its index is stored separately at .semantic-search/jina/.

Queries emit JSON Lines. Each result includes a similarity score, backend, source-relative path, original-file SHA-256, page or line/chunk anchor, recognized standard identifiers, and matched excerpt. --source restricts results to a case-insensitive substring in the relative path. Standard-code metadata recognizes Florida forms such as SC.8.SL.2.1 and NGSS forms such as 5-ESS1-1 or MS-LS2-4; it is a locator aid, not a validated standards-code parser.

Ingestion and exclusions

The indexer inventories every file below the corpus root except generated index files, .git, and SHA256SUMS.txt; the checksum manifest is omitted to avoid a self-referential inventory hash. It extracts corpus .pdf, .txt, .md, .html/.htm, .json, .csv, and legacy .ppt files. PDFs are extracted page by page with PyMuPDF; plain-text material is chunked with line anchors; CSV rows remain searchable as text with physical line anchors; .ppt text is extracted with catppt where installed (legacy PowerPoint slide numbers are not retained). Source hashes are computed from the original file, not the extracted text. The inventory records each file’s indexing/exclusion status, including unsupported formats and PDFs with pages that yield no text. Existing PDF and extracted-text pairs are both retained; this preserves each source’s own locator but may yield near-duplicate results. Root-level analysis reports and workflow documentation plus the indexer source code are excluded from evidence ranking and listed with their hashes as generated/unsupported exclusions. Retrieval output should be consolidated by source family during review.

The refreshed inventory has 162 records: 136 indexed (132 through the standard extractors and four through catppt) and 26 excluded. It includes the FDOE 2010 memo and searchable alignment CSV for the 1996-to-2008 assessment crosswalk. The three source .xls workbooks are retained with hashes and marked unsupported by the current indexer; their searchable, normalized rows are in the CSV. The inventory also includes the 2026 benchmark register, omission, legacy forward-candidate, legacy reverse-screen, legacy task-equivalence, Indiana reverse-screen, 2008 reverse-screen, and unresolved-draft reverse-screen CSVs; the generator for the 196-row legacy task-equivalence table; all six row-level 2008 source-first review appendices; all six row-level 1996/GLE source-first review appendices; four row-level reviews of all 135 draft benchmarks initially marked unresolved; the full benchmark variant graph; the FDOE listening-tour release source note; and the nine grade-level Indiana 2000–01 K–8 standards booklets with extracted text. The graph carries 682 row-level 1996/GLE review assertions across all 196 source IDs and 405 distinct 2026 draft benchmarks. It is scoped to the files present inside this corpus folder. It cannot index copyrighted sources available only through web readers, inaccessible Internet Archive/FDOE snapshots, unreadable/corrupt files, images embedded in PDFs, or files in unsupported formats; those limitations appear as inventory exclusions or remain outside the corpus inventory. The four 2007 .ppt files are included through extracted text where the installed catppt converter can read them. The index currently contains 36,568 chunks.

Search lead from the first query pass

A query restricted to sources/alt-florida—expect contrary opinions because interpretations of the same climatic data can vary widely—ranks the California Department of Education’s 2006 Science Framework first: 0.44306 in the TXT extraction, lines 13919–13940; 0.44278 in the PDF, Grade 6–8 climate instruction, PDF p. 280, extracted page text lines 19–39. The passage says students “should be advised to expect contrary opinions because interpretations of the same climatic data can vary widely,” in a context that also discusses greenhouse-model instruction. The PDF and corresponding TXT extraction are two representations of one source, not independent corroboration. This is a candidate rhetorical/content-source lead only. The identical query restricted to sources/2026 returned no comparable passage; its highest result was a general Earth/space history table (0.26041, sources/2026/fl-tables.txt, lines 952–1001). A literal search of the 2026 source extracts also returned no match for the queried sentence. These are negative search results, not proof of absence or a finding that the California wording was lifted. Check exact wording and nearby context manually.

Reproducibility

The index is deterministic for the same extracted text and pinned random seed (1729); index-meta.json records the library versions, matrix dimensions, and backend settings. Rebuild after adding or changing any file. Each output record contains the source’s current SHA-256 so it can be checked against SHA256SUMS.txt or recalculated with sha256sum.

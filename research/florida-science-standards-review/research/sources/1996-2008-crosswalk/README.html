FDOE FCAT assessment alignment: 1996 legacy codes to 2008 NGSSS

Research added October 22, 2026. This folder preserves the official assessment-alignment evidence located for the 1996-to-2008 transition. The original XLS files are primary evidence; the CSV is a reproducible normalization for comparison and semantic search.

Why these files matter

FDOE’s Office of Mathematics and Science newsletter, Issue 4 (March 18, 2008) says the department and its Assessment Office would develop a crosswalk comparing the 1996 science content standards with the newly adopted standards. FDOE’s DPS-2010-50 memo, p. 3, later states that a similar science crosswalk is given in the 2009 and 2010 Content Focus reports. It cautions that there is generally no one-to-one correlation between the old Sunshine State Standards and the NGSSS in science and mathematics.

FDOE’s Content Focus Reports archive lists the 2009 and 2010 science workbooks. The fileparse URLs on www.fldoe.org returned HTTP 403 during retrieval; the agency’s origin.fldoe.org host served the workbook files. The memo, workbook sources, and extracted text are preserved here.

What the workbooks contain

Each report has assessment sections for grades 5, 8, and 11. The 2010 workbook prints those grade titles. The 2009 text export omits them, so its assessment grade is inferred from the legacy code’s grade-cluster digit; all 2009 sections are consistent with the explicitly titled 2010 layout.

The Benchmark field uses legacy codes such as A123. In the recovered 1996 standards, that code identifies area A, Standard 1, grades 3–5 cluster, benchmark 3: SC.A.1.2, benchmark 3. The adjacent 2008 alignment field records one or more new benchmark codes for the assessed content focus. For example, the 2009 row A123 / Conservation of mass / SC.4.P.8.3 links that 1996-era benchmark code to a 2008 benchmark alignment. N/A is preserved when a new benchmark alignment was not listed.

The normalized file contains 276 rows: 130 from 2009 and 146 from 2010, covering 116 legacy benchmark codes across 49 1996 standard/grade-cluster codes. It has 247 rows with a 2008 benchmark alignment and 29 marked N/A. Repeated old or new codes are retained because separate content-focus descriptions and assessment rows are meaningful records.

This is an assessment-level crosswalk witness, not a complete benchmark-by-benchmark equivalence table. It describes tested content-focus rows and explicitly allows non-one-to-one relationships. An unlisted 1996 benchmark cannot be called omitted from the 2008 standards on the basis of this workbook alone. The codes and crosswalk can, however, serve as an additional route for tracing a 1996 benchmark into 2008 and then checking the current 2026 register.

Reproduce the CSV

Requirements: Python 3 standard library and the xls2csv executable from catdoc.

python3 ../../tools/extract_fcat_alignment.py

The extractor retains the original workbook files, normalizes each assessment row, decodes the old code into a 1996 standard code plus benchmark number, points to the relevant 1996 source-text file and standard heading line, and preserves each 2008 alignment. For 2009 it derives grade level from the legacy code’s cluster digit; for 2010 it reads the printed title and checks it against that digit. The original XLS files remain authoritative if the normalized output differs.

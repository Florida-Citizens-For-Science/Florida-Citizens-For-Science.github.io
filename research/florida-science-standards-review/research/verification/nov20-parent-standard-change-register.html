How to read this table

All coded parent-standard descriptions with wording or code changes, plus moved or unmatched records.

“Added” and “removed” are normalized word-token counts from the local comparison; they are not measures of educational scope or information. Candidate reference coverage means the changed wording had exact five-word phrase overlap with a local source file. It does not establish that the draft authors used that source, or settle conceptual coverage. “No strong overlap” is not evidence that no reference covers the topic. Viewpoint notes identify explicit topical signals; they do not infer motive.

The old SC.912.CB.11 description moves to SC.912.CB.12 while SC.912.CB.11 receives different molecular-genetics wording. The plant description moves intact from SC.K.P.1 to SC.1.K.1. These are code moves/reorganization, not necessarily net-new expectations.

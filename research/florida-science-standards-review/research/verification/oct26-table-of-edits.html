How to read the change labels

  • Existing code · wording changed: the same code has a revised sentence, with no exact sentence match elsewhere.

  • New code · carries earlier text: a new code carries an exact sentence from the first-round draft; it is not treated as a new concept.
  • New code · no exact earlier sentence: no exact first-round sentence match was found. That does not establish conceptual novelty.
